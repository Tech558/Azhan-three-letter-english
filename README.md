# Three-Letter Word Quiz (UKG)

**Run:** put index.html, style.css and script.js in one folder and double-click index.html (Chrome, Edge, Firefox or Safari). No server or internet needed.

**Add words:** Home → "Teacher / Parent area". Enter the word, choose the missing-letter position, type 5 letters and tick the correct one, upload picture + question audio (MP3/WAV), optionally a full-word audio, then "Save word". Use "Add sample words" for a quick test.

**Backup:** "Export backup (JSON)" saves everything including pictures and audio. "Import backup" restores it on another computer.

**Note:** Data lives in this browser. Clearing site data erases it, so export a backup regularly.
